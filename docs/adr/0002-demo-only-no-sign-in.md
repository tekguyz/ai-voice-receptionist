# Demo only: no sign-in and no real accounts

This app is a show-off demo, not a product that business owners sign in to.
It has a landing page and a one-click demo, and nothing else. So it has no
"Sign in" link, which is a deliberate exception to rule 9 of
`claude-config/DEMO-STANDARD.md`. A real receptionist for a client is built per
client, with that client's phone line, call forwarding and accounts. Those
screens (for example the call-forwarding setup in the design references) are
out of scope here.
