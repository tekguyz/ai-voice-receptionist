# Test Calls run in the browser, never on a phone line

A Visitor talks to the Receptionist through the browser microphone. The app
never dials a phone number. The old demo (`Real-Stone-Granite-AI-Experience`)
called the Visitor's phone, so it had to check each number against a list
typed into the code, and most Visitors could not get a call at all. A browser
call needs no number, so one press starts it, and nobody can use the demo to
make us call a stranger. Each Test Call still costs money, so calls are capped.

## Considered Options

- **Call the Visitor's phone.** Rejected: it needs a number check, and an open
  form that dials any number invites abuse.
