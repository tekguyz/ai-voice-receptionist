# Plan: the zip code on every address (#29)

Size: feature. The issue is the spec. Decided with the founder on 2026-10-14:
re-record the Sample Call, because the landing work order, the Sample Call
screen and the Call Notes all show it.

## Design

- An address stays one field, `address`. The zip goes at its end:
  `2215 Palm Shadow Lane, Miramar, FL 33027`. So the Call Story, the Call
  Notes, the ticket and the confirmation text show it with no new code.
- Luna asks for the zip with the address (one question), reads the address
  back with the zip, records it with the zip, and says the zip in the
  confirmation. Spanish: the same, in Spanish.
- People say a zip digit by digit ("three three one three seven"). That is
  the natural way, so the actor does it too. The street number stays
  "forty-four fifty".
- `luna:report` fails a call whose recorded address has no 5-digit zip.
- Made-up zips that fit each city: Miami 33137, Miramar 33027, Westchester
  33165, Coral Springs 33065, Pembroke Pines 33029.
